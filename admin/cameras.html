Hooking up the vision script

One still camera per floor. After each frame, send the grid coordinates that contain a car. Coordinates are "row_col" on this floor's plan — the same grid you drew on the Layout page. The backend maps cells to bays and records what the camera sees without touching bookings.

# Python — after each processed frame
import requests
FN = "https://us-central1-smart-park-3b9a8.cloudfunctions.net/reportCameraFrame"

def report(lot_id, floor, car_cells):
    # car_cells: list of "row_col" strings, e.g. ["3_1", "3_2", "5_4"]
    requests.post(FN, json={"data": {
        "lotId": lot_id, "floor": floor,
        "cells": car_cells, "source": "cam-ground-1"
    }})

report("phoneix-marketcity", "Ground", ["3_1", "3_2", "5_4"])

Callables want the body wrapped in {"data": {...}}. Send the full set each time — anything not listed is treated as empty. To let the camera drive bookings automatically, call applyCameraFrame with {"lotId","floor"} after each report.
